# Human work rises into oversight, helped by throwaway software

Karpathy ends his post on output formats with two claims. First, as models get better they do more
of the legwork alone, so more human work moves up the abstraction ladder into oversight and
understanding. Second, models can help with that too. Intelligence and code are becoming
abundant, so you can ask for large, custom software artifacts that you will discard after use,
such as web apps and video explainers. These would never have been worth building before. His
advice is to push on this and see what happens.

## Apply

- When you must review a big change, ask for a one-off viewer: a diff explorer, a dependency graph
  or a dashboard of test results.
- Treat these artifacts as disposable. Do not maintain them. Generate a new one next time.
- Spend your own time on judging results, not on producing them.
