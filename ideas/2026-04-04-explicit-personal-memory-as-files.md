# Personal AI memory should be plain files you own

Farza built a personal wiki of 400 articles from his diary, notes and messages. Karpathy used it
as an example of a better way to personalise AI than the usual promise that the AI improves with use. He gives four reasons. It is explicit: you can see what the AI knows and does not
know. It is yours: the data stays on your computer, not locked in a provider. It follows "file
over app": plain markdown and images work with any tool, and agents can use the whole Unix
toolkit on them. It is bring-your-own-AI: Claude, Codex or an open model can all plug in, and you
could finetune a model on the wiki. He admits this takes some file management, and says agent
skill is a core skill of this century.

## In his words

> "File over app."
> — Andrej Karpathy, 2026-04-04

## Apply

- Keep what your AI should know about you in a folder of markdown files, not only in a vendor's
  memory feature.
- Ask the agent to build and maintain it from your notes, then read it and correct errors.
- Keep the files in git or a synced folder, so any tool or model can use them.
