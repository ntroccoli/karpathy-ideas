# Keep one note you append to and review

Karpathy has used one single text note for years. He keeps it in a notes app and calls it
"notes". He adds every idea, to-do, quote, command or experiment log to the top as plain text. He
adds no folders and almost no tags. Old items sink under newer ones. From time to time he
scrolls down, skims, and copies anything that still deserves attention back to the top. He
merges related items and rarely deletes. Items that never get rescued stay findable with
search, but they stop competing for attention. Writing something down lets him clear his
working memory and move on.

## In his words

> "One text note ftw."
> — Andrej Karpathy, 2025-03-19

## Apply

- Create one note with one fixed name. Put new text at the top, never in a new note.
- Skip tags. Use only a few search prefixes for action types, such as `watch:`, `listen:`,
  `read:`.
- Schedule a short review: scroll down, copy what still matters to the top, merge items that
  repeat the same thought.
- Use the same note for scratch work: shell commands you forget, experiment commands and
  results, a morning to-do list.

## Context

- Written in March 2025, before the LLM-wiki style of note keeping. For the LLM-driven
  alternative, browse the `knowledge-management` theme.
- Our reading: the "review by gravity" rule is a cheap form of spaced attention, and it works
  with plain text that an LLM can also read.
- He still uses Obsidian for concrete projects, but not for daily notes.
