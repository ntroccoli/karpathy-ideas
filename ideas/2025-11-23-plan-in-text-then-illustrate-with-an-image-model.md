# Plan in text first, then ask an image model to illustrate, and re-roll

Karpathy tried Nano Banana Pro, an image model that also reasons. For a workout plan he first asked for a weekly plan in a separate text chat, giving his goals and preferences. Then he asked the model to illustrate the whole week, and each day, as posters to print. He also had it solve exam questions inside the exam page image, with doodles and diagrams, and fix a math problem "in my handwriting". It makes mistakes: one poster showed an odd push-up. You re-roll until it is right, and if it loops you start a new conversation. A second model can check the content. He sees this as a sign of a future where the model's interface is an intelligent canvas.

## Apply

- Settle the content in a text conversation. Only then ask for images.
- Ask for the whole set (a week), then for each item, so the style stays consistent.
- Check facts and spelling in the picture yourself, or paste it to another model; re-roll on mistakes.
- When the model gets stuck in a loop, start a new conversation with the finished text.
