# Ask agents for long documents and notebooks, and read them in the IDE

Karpathy still keeps an IDE open next to his agents. One reason is output format. He asks agents for Jupyter notebooks for analysis and for longer Markdown documents, and previews them in the IDE. He finds this much better than reading text in a terminal. When you ask for docs or summaries, agents can be more detailed and clear, and he likes that.

## Apply

- End a task with: "Write a report as a Markdown file with tables and the key results first."
- For data work, ask for a Jupyter notebook with the code, charts and short notes.
- Open the files in an IDE with Markdown preview, not in the terminal log.
