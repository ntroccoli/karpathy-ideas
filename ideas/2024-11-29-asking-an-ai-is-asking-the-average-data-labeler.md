# Asking an AI is like asking the average data labeler

Karpathy says that when you ask an AI, you are closer to asking an average data labeler, who is skilled in code and math, whose style was distilled into the model. RL changes this only in verifiable domains. On judgment questions you get a competent consensus, not a unique expert view.

## In his words

> "asking the average data labeler"
> — Andrej Karpathy, 2024-11-29

## Apply

- For judgment calls, treat the answer as a competent consensus. Ask for dissent and for sources.
- Ask for the opinion of a named type of expert, with the model simulating them. See [there is no 'you'](2025-12-07-llms-simulate-there-is-no-you.md).
- Use checks and tests where you can, since that is where models exceed the labeler.
