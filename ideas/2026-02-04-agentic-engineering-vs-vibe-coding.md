# Agentic engineering is the professional form of vibe coding

On the first anniversary of "vibe coding", Karpathy says it fit throwaway projects and demos when models were weaker. A year later, programming with agents is becoming a default for professionals, but with more oversight. The aim is the leverage of agents with no loss in software quality. His preferred name is "agentic engineering". "Agentic" means you rarely write code yourself (about 99% of the time) and you direct agents and review. "Engineering" means there is real craft, expertise and depth to learn.

## In his words

> "programming via LLM agents is increasingly becoming a default workflow for professionals"
> — Andrej Karpathy, 2026-02-04

## Apply

- Use vibe coding (accept output unchecked) only for throwaway work.
- For real software, keep tests, review and a human who owns each design choice.
- Treat agent use as a skill: write down what works, and share it with the team.
