# Read with an LLM in three passes

Karpathy describes a reading habit that he counts among his top uses of LLMs. Pass one: read the text yourself. Pass two: ask the model to explain or summarize it. Pass three: ask questions about it. He ends up understanding more than with a single pass. He also expects writers to write for an LLM, which then adapts the idea to each reader.

## In his words

> "I'm writing this for an LLM"
> — Andrej Karpathy, 2025-11-17

## Apply

- Read a paper or doc once on your own before you ask for a summary.
- After the summary, ask the model to quiz you or to challenge a claim in the text.
- Write your own docs so an LLM can reread them: clear headings, plain text.
