# Write new knowledge for AI readers, not as a PDF

A researcher complained that nobody has time to read papers. Karpathy answered with two claims.
First, as AI improves, a person's real contribution is original knowledge: something that cannot
be worked out by reasoning from what is already online, such as the result of an experiment.
Second, such work should be written for AI readers as much as for people. A PDF is hard for a
model to use. A git repository with the analysis code, results in CSV files and explanations in
markdown is easier. He expects most attention soon to be LLM attention, and he sees room for a
"research app" built around that. In September he repeated the first point to a new AI-science
lab: we will not reason our way to Dyson spheres.

## In his words

> "PDF is an AI unfriendly format."
> — Andrej Karpathy, 2025-07-10

## Apply

- Publish results with the code that made them, the raw numbers as CSV, and a short markdown
  explanation.
- Put the experiment, not only the conclusion, in the repository.
- Give a model your repo and ask it questions, to test whether it can follow your work.
