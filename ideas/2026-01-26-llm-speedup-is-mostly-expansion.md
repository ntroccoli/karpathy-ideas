# LLM help is less a speedup than an expansion

Karpathy says it is hard to measure the speedup from LLM help. He feels faster at tasks he already planned. But the larger effect is that he does more in total. Two reasons: code that was never worth writing is now cheap to write, and code outside his skill is now within reach. So the gain is partly speed and partly a wider range of work. A related note: agents also lower the cost of stamina. They do not tire or lose heart. He calls stamina a core bottleneck of work, and LLMs have raised it a lot.

## In his words

> "certainly it's speedup, but it's possibly a lot more an expansion."
> — Andrej Karpathy, 2026-01-26

## Apply

- Do not judge agent use by hours saved on old tasks. Also count the tasks you now do that you would have skipped.
- Make a list of small tools you never built because of cost. Give one to an agent this week.
- Give the agent hard, long problems and let it retry. It does not get discouraged.
