# Cognitive load is what matters in software engineering

Karpathy endorsed an essay titled Cognitive load is what matters. He called it the most true, and least practiced, viewpoint of software engineering. The idea: good code is code that a person can hold in their head. Our reading: this matters more as agents write more code, because people must still review it.

## Apply

- Ask the agent for simple, flat code with few abstractions and short functions.
- In review, ask: could I explain this in two minutes? If not, simplify.
- Delete code paths and options that no one uses.
