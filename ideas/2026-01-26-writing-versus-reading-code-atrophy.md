# Writing code can atrophy while reading code stays strong

Karpathy notices that his ability to write code by hand is slowly fading because agents write most of it. He argues that generating code and judging code are different skills. Many small syntax details matter for writing, but you can review code well without remembering them. A related risk came from a reply he praised: "comprehension debt". When an agent produces something that seems to work, it is tempting to move on without understanding it. Our reading: review keeps the skill that matters, but only if you actually read and understand the result.

## In his words

> "Generation (writing code) and discrimination (reading code) are different capabilities in the brain."
> — Andrej Karpathy, 2026-01-26

## Apply

- Keep one practice habit that needs you to write code by hand, such as a small weekly exercise.
- When an agent finishes, ask it to explain the change. Do not merge what you cannot explain.
- Track "comprehension debt": note the parts of the codebase that nobody has read, and schedule time to read them.
