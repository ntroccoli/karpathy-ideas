# Cheaper software raises the demand for software

Asked about jobs, Karpathy says he is no economist and the answer will differ by field. On
software he is cautiously optimistic. Software was scarce and costly. As it gets cheaper, demand
can rise, which is the Jevons paradox; bank tellers and cash machines are the usual example.
People need not accept tools built for others, and code can be changed at will. For now he sees
AI as a tool that makes some tasks of a job much faster. In June 2026 he said he feels the
paradox in his own work. He asks for far more software than before: explainers, visualizers,
dashboards, one-off apps for a single project, a test suite ten times larger, and research runs
that report in custom HTML. He also warned that it has never been so tempting to stop reading the
code, and that production code still needs review.

## Apply

- List the small tools you skipped because they were not worth a day. Ask an agent for them now.
- Ask for a bespoke dashboard or viewer for each project instead of a generic tool.
- Ask the agent to grow your test suite, and to optimize code against those tests.
- Treat your job as a bundle of tasks. Learn first the tools for the tasks an agent can already
  speed up.
- Keep human review for production code, even when the model looks reliable.
