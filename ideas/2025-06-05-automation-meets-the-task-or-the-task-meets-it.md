# Either the automation adapts, or the world does

Someone argued we should not train models for computer use, since the web was built for humans. He replied that this ignores inertia (COBOL is still in wide use). He framed the question in general terms: do LLMs adapt to all existing software, or does software adapt to LLMs, with text forms and APIs? The same holds for robots and warehouses. Most of the time it is a bit of both. His prediction: in software about 80% of the change will be software adapting, because flipping bits is cheap. In hardware it is the reverse, because moving atoms is costly.

## In his words

> "Either an automation meets all the tasks, or all the tasks meet the automation."
> — Andrej Karpathy, 2025-06-05
