# Judge an agent as you would a junior intern

Karpathy says the capability to watch is not PhD-level problems. It is the junior intern: you say set up your Slack, read the onboarding docs, do this task, and check in next week. Our reading: that test needs long coherent work, not clever answers. It is a useful way to rate an agent and to write briefs for one.

## In his words

> "whether you'd hire it as a junior intern"
> — Andrej Karpathy, 2024-12-14

## Apply

- Write the agent instruction file like onboarding docs: goals, layout, commands, who decides what.
- Assign week-sized tasks with a clear check in, and review at the check in.
- Rate a new agent by one real task of this size.
