# Field notes

What happened when we applied an idea from this collection in real work.

Each note is one file named `YYYY-MM-DD-short-slug.md` and covers:

- **Idea:** link to the idea file.
- **Setting:** the project, the tools and the model used.
- **What we did:** the concrete steps.
- **Result:** what worked, what did not, with numbers where possible.
- **Verdict:** keep, adapt or drop.

The idea file links back to its notes in a "Field notes" section.
